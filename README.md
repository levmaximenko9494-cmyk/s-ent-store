# Scent Store — магазин с backend и админ-панелью

## Запуск локально
1. Установите Node.js 20+.
2. Скопируйте `.env.example` в `.env` и задайте `JWT_SECRET`, `ADMIN_EMAIL`, `ADMIN_PASSWORD`.
3. Выполните `npm install`.
4. Выполните `npm start`.
5. Магазин: `http://localhost:3000`
6. Админка: `http://localhost:3000/admin`

## Что теперь реально хранится
- товары и остатки — SQLite;
- заказы — SQLite;
- позиции заказов;
- статусы заказов;
- администратор с хешированным паролем;
- JWT-сессия админки.

## Важно для боевого запуска
Перед реальными продажами нужно:
- заменить dev-пароль и JWT_SECRET;
- включить HTTPS;
- подключить реальный домен;
- настроить резервные копии БД;
- подключить платёжный провайдер и webhook подтверждения оплаты;
- подключить службу доставки;
- настроить email/SMS уведомления;
- добавить юридические документы и политику обработки данных.
